O pipeline atual do Roblox usa peças nativas/procedurais para manter o mundo sincronizável via Rojo e não depende de modelos DAE publicados. Os nomes dos elementos escolhidos ficam registrados no catálogo de cenário; modelos externos podem ser importados no Studio em uma etapa posterior.
